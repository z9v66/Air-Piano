# 🎹 Air Piano

An interactive web-based musical tool built with computer vision concepts. It allows users to play musical notes simply by moving their hands in the air without needing any physical keys. The application tracks hand gestures and movements in real-time directly through the browser.

### 🛠️ Tech Stack
- **HTML5 & CSS3:** Clean layout and responsive styling.
- **JavaScript (app.js):** Real-time interaction, logic handling, and audio/gesture control.

### 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Allow camera/gesture access if prompted and start playing!
